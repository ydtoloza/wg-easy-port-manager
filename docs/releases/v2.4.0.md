# WG-Easy Port Manager 2.4

Version 2.4 redesigns the administration panel around network traffic. It is
a frontend-only release: the API, configuration files and environment
variables are unchanged.

## Highlights

- **New admin panel layout**: a calmer, standard-looking interface built from
  plain boxes, tables and native controls. Dark (black) theme by default, with
  a light/dark toggle; a previously stored theme choice is kept.
- **Traffic first**: a full-width `wg0` chart (2m / 1h / 24h / 30d) with a
  legend table showing the current rate, average, peak and total transferred
  in the selected range. Clicking a series hides or shows it. Series are named
  from the clients' point of view (client download / client upload).
- **Server and interfaces**: CPU and RAM charts, live rates and peaks for
  `wg0` and the WAN device, and peaks/totals since start. The traffic panel is
  now shown by default; it can still be hidden from the header.
- **Clients table** with text search and a status filter (connected,
  disconnected, disabled). Per-client data is limited to WireGuard's
  cumulative counters.
- **Client detail and All ports views** at `#/client/<id>` and `#/ports`, so
  the browser back button works. Port forwarding (add, edit, delete, random
  seeding port, reachability probes), network policy and every dialog keep
  their previous behaviour.

## Container images

- Stable: `ghcr.io/ydtoloza/wg-easy-port-manager:2.4.0`
- Compatible minor alias: `ghcr.io/ydtoloza/wg-easy-port-manager:2.4`
- Latest stable: `ghcr.io/ydtoloza/wg-easy-port-manager:latest`

Images support `linux/amd64` and `linux/arm64`.

## Upgrade notes

- No required environment or configuration changes.
- Browsers keep a stored theme; users who never chose one now get the dark
  theme. The collapsible "all ports" card is replaced by the **Ports** tab.
- New interface strings are translated to English and Spanish; other
  languages fall back to English for those strings.

Back up `/etc/wireguard` before upgrading. Follow [the VPS deployment guide](../vps-deployment.md) for installation, validation, upgrades and rollback.
