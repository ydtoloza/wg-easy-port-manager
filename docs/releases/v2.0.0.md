# WG-Easy Port Manager 2.0

Version 2.0 adds per-client network policy management while preserving the existing WireGuard and DNAT workflow.

## Highlights

- Default IPv4 and IPv6 isolation between WireGuard clients.
- Symmetric peer exceptions managed from the web interface.
- Outbound blocking presets for common protocols and services.
- Custom TCP or UDP ports and ranges per client.
- Atomic `nftables` updates with rollback across memory, disk and host state.
- Fail-closed transitions while deleting, disabling, restoring or changing a client address.
- Immutable multi-architecture images for every commit.
- Hardened authentication, backup validation, CSP and session handling from the security releases leading to 2.0.

## Container images

- Stable: `ghcr.io/ydtoloza/wg-easy-port-manager:2.0.0`
- Compatible minor alias: `ghcr.io/ydtoloza/wg-easy-port-manager:2.0`
- Latest stable: `ghcr.io/ydtoloza/wg-easy-port-manager:latest`

Images support `linux/amd64` and `linux/arm64`.

## Upgrade warning

When an older configuration is loaded, every existing client receives the isolated policy by default. After upgrading, open each client's network policy and explicitly select any peer pairs that must continue communicating.

Back up `/etc/wireguard` before upgrading. Follow [the VPS deployment guide](../vps-deployment.md) for installation, validation, upgrades and rollback.
