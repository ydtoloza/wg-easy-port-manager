# WG-Easy Port Manager 2.5

Version 2.5 adds users without accounts: an access code links WireGuard
profiles to a person and opens a small self-service portal.

## Highlights

- **Users tab** in the admin panel: create a user and copy their access code
  (shown once), issue a new code, allow or block profile creation, delete the
  user (their profiles keep working, unlinked).
- **Link existing profiles** from each client's detail page.
- **User portal** at `/portal.html`: sign in with the code, see the linked
  profiles and their open ports, download the `.conf` or show its QR code.
- **Self-created profiles**: when allowed, a user can create one IPv4 and one
  IPv6 profile. Each one opens a single port (TCP and UDP, same internal port)
  chosen from 5 free ports offered by the server. The IPv4 profile tunnels
  `0.0.0.0/0`, the IPv6 profile tunnels `::/0`.

## Upgrade notes

- No required environment changes. `wg0.json` gains an optional `users` map
  and two optional client fields (`ownerId`, `family`); older backups restore
  unchanged.
- To publish only the portal, put a reverse proxy in front that forwards
  `/portal.html`, `/js/portal.js`, `/css/`, `/img/` and `/api/portal/` and
  nothing else, and set `TRUSTED_PROXY_IP` so rate limits see the real client
  address. Keep the admin port private (for example, Tailscale only).

Back up `/etc/wireguard` before upgrading. Follow [the VPS deployment guide](../vps-deployment.md) for installation, validation, upgrades and rollback.
